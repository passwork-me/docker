# Deprecated Repository for Legacy Versions (v5 and earlier)
This repository is intended for legacy versions of Passwork — version 5 and earlier.

## Starting from version 6, this repository is no longer used
Docker images and deployment files for Passwork v6+ are delivered via our client portal.
Important
If you are using Passwork version 5 or earlier, we strongly recommend upgrading to the latest version to benefit from up-to-date features, improved security, and active support.

## Where to get Passwork v6+
Distributions and Docker files are available in the client portal.
If you have any questions or encounter issues during the upgrade, please contact our technical support.
